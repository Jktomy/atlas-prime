# Rimuru

Rimuru is Atlas’s durable noncanonical library for external-intelligence records, reusable patterns, evaluated tools, rejected approaches, test ideas, source and license bindings, and future inspiration.

## Authority

Rimuru records are evidence and possibilities. They never override merged Prime, Mission Control, Aegis, Noctua, Ares, Strikeforce, Quest state, protected systems, runtime truth, READY, or permanence.

## Paths

```text
knowledge/rimuru/registry-r01.json
knowledge/rimuru/records/<record-id>.json
knowledge/rimuru/code-capsules/<capsule-id>.json
knowledge/rimuru/lineage/
```

Only schema-valid JSON records and public-clean Markdown lineage may be committed. Binaries, archives, package caches, generated dependency trees, executable workflows, and imported repositories are forbidden.

## Promotion boundary

A Rimuru finding may inspire a separate Preview or Mission. It cannot self-admit that Mission, alter doctrine, install a dependency, activate a service, or enter runtime import and deployment paths.

## Review and expiry

Every record binds source revision, observed time, verification state, license, review trigger, and supersession status. Source drift requires re-Harvest before consequential use.
