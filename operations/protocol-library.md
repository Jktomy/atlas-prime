# Atlas Protocol Library

- **Janus** is Codex's governed intake and transition Operation. It houses
  **Argus**, which routes intake and sunrise review without silently promoting it
  to source.
- **Spark** captures an idea or opportunity as noncanonical material.
- **Ciel Harvest** is read-only external-source verification under Operation
  Ciel. It produces a source-bound noncanonical Harvest Record and performs no
  mutation.
- **Absorb** invokes **Gluttony** against a completed Harvest and may prepare
  noncanonical records or later Mission proposals without self-promotion.
- **Rimuru** is the noncanonical external-intelligence library.
- **Emberline** is an immutable Preview and decision package; it does not execute.
- **Quest Emberline** is a structured, non-executing presentation bound to
  canonical Quest continuity.
- **Athena Weave** binds one exact change.
- **Aegis Break** is Athena's primary bounded Prime change method while GitHub is
  canonical. It governs safe route selection and construction over an exact
  atomic GitHub-native substrate and is never a standing publisher or bypass.
- **Spear** is Athena's platform-neutral exact-Weave delivery to Thread Engine.
  Historical component proof remains accepted; GitHub Direct Spear ingress is
  retired and future Gitea use remains separately gated.
- **Arrow/Bow** is explicit Jayson/Artemis delegated immutable delivery to Thread
  Engine.
- **Thread Engine** is a preserved mission-scoped draft-PR component, not the
  current GitHub default publisher.
- **Sword** is one sealed mission-specific package containing exact payload,
  build, repair, execute, recovery, evidence, and campaign identity.
- **Oathbringer** is Jayson's live-proven independent recovery publisher and Sword
  method. BUILD, REPAIR, and separately authorized EXECUTE remain exact-state
  bound.
- **Phoenix Blade** is Athena executing an exact Sword; it is not generic direct
  repository work.
- **Shardplate** is an AI-assisted work surface, never a route, credential,
  engine, candidate, approval, or permanence authority.
- **Shardblade** is the bounded permanence executor for one exact unchanged head.
  READY and MERGE remain separate and never author, repair, or widen.
- **Fresh Clone First** is one repository substrate. Exact GitHub-native atomic
  tree/commit construction is equivalent only when it preserves the same locks,
  Candidate Seal, single-parent topology, draft stop, validation, and readback.
- **Spirallight**, **Chromelight**, and **Emberlight** identify trusted reported
  token accounting only.
- **Phoenix Burn/Reborn** governs controlled removal, reconstruction, restore,
  and rollback.
- **Full Atlas Sunset** is complete lifecycle closeout with exact Preview,
  approval, Feather, Sunset, Sunrise, Lesson Harvest, recovery, and readback.
- **Feather** is immutable exact-context evidence.
- **Golden Wing** is a reusable-lesson candidate and never promotes itself.
- **Dawnshard** is a bounded, stale-aware, restart-safe Coppermind projection for
  Athena, never a second source of truth.

Protocols never broaden authority merely by being named. Every invocation binds
the repository, exact source, allowed actions, protected boundary, stop point,
evidence, and rollback.
