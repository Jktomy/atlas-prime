# Athena Routes

This module preserves bounded local construction, hosted Jayson/Artemis
Arrow/Bow intake, historical Direct Spear components, exact identity and replay
validation, and evidence helpers.

Current route ownership is:

```text
Current GitHub ordinary Prime work:
Athena -> Aegis Break -> exact atomic GitHub-native transaction

Explicit methods:
Athena -> exact Sword -> Phoenix Blade
Jayson / Artemis -> Arrow -> Bow -> Thread Engine
Jayson -> exact Sword -> Oathbringer
Future proven Gitea -> Spear -> Thread Engine adapter
```

`governance/aegis-break-primary-route-contract.md` controls current-GitHub
precedence. This module does not make Aegis Break a standing writer or second
repository engine.

## Safe-declared free-form intake

`python -B -m tools.athena_routes.free_form_intake --fields <fields.json>
--output-dir <new-directory>` accepts a closed local public-clean mission-fields
object and atomically creates one new output directory outside canonical source.
It constructs deterministic carrier, Preview, receipt, and retained compiled
files. It has no workflow dispatch, Git, branch, PR, READY, merge, settings, or
standing authority.

## Owner-guided hosted publisher

`guided_publisher preview|execute` is an explicit Jayson/Artemis Arrow/Bow
launcher over the historical hosted workflow. It is not Athena's default route.
It preserves exact carrier, base, replay, identity, and draft-stop boundaries and
never becomes a second writer.

## Retired GitHub Direct Spear ingress

The client, crypto, ingress implementation, schemas, fixtures, and accepted
historical proof remain in source. The active
`.github/workflows/athena-spear-issue-ingress.yml` entrypoint is absent, so no
new Issue comment can dispatch Direct Spear key, Preview, Execute, or Resume.

The source remains useful for audit and Mission #353 future Gitea design. It
cannot be selected by automatic current-GitHub routing, and source presence does
not prove live acceptance. Restoring a GitHub ingress requires a new reviewed
architecture and separate settings/secret authority.

## Historical fresh-origin construction

`fresh_work_bridge` and its schemas are retained as inert historical construction evidence.
It has no dispatch or remote-write path and is never required for Aegis Break,
Phoenix Blade, delegated Arrow/Bow, or future separately proven Spear.

## RP-C01-M05 parity join

`m05_parity` preserves exact historical direct-Spear and hosted Arrow/Bow
compiler/adapter evidence. It emits closed evidence only and cannot execute,
retry, merge, confer permanence, or redefine the current default route.

## Generated projection diagnostics

Ordinary Prime validation builds the five diagnostics in temporary storage and
emits a machine-readable receipt. It creates no post-merge publisher Mission,
branch, PR, READY transition, or merge.
